# Agent 迁移架构设计

## 五层迁移模型

将 Agent 的全部自定义状态抽象为 5 个可移植层：

```
┌──────────────────────────────────────┐
│  README.md  ← 新 Agent 的入口        │
├──────────────────────────────────────┤
│  层1: Skills                         │
│  ├── Tier1: onezion-* (硬编码必带)    │
│  └── Tier2: agent_created (推荐)      │
├──────────────────────────────────────┤
│  层2: MCP 配置                       │
│  └── mcp.json + OAuth 状态           │
├──────────────────────────────────────┤
│  层3: Memory                         │
│  ├── MEMORY.md (长期)                │
│  └── daily/*.md (30天内)             │
├──────────────────────────────────────┤
│  层4: 聊天记录（双层策略）             │
│  ├── sessions_metadata.jsonl (元数据) │
│  ├── raw_messages/ (完整JSONL消息)    │
│  ├── LLMWiki_simplified.md (简化)     │
│  └── context_brief.md (当前状态)      │
├──────────────────────────────────────┤
│  层5: 密钥 (可选)                    │
│  └── Keychain 导出 → env 文件        │
└──────────────────────────────────────┘
```

## 设计决策

### 为什么用命名规则而非 AI 判断分类？

使用 `onezion-*` 前缀作为 Tier 1 标识：
- **硬编码** = 0% 错误率，确定性
- **AI 判断** = 概率性，会猜错哪些 skills 重要

命名规则是最低成本、最高可靠性的分类方案。

### 为什么聊天记录采用双层策略？

**问题**：完整聊天记录直接丢入新 Agent 可能爆 context window，但只丢摘要又丢失了深度检索能力。

**方案**：双层策略 — 原始版 + LLMWiki 简化版

| 层 | 文件 | 用途 | 大小 |
|----|------|------|------|
| 元数据 | `sessions_metadata.jsonl` | 快速浏览所有对话标题和时间 | 小 |
| 原始版 | `raw_messages/*.jsonl` | 深度检索、完整历史回溯 | 较大 |
| 简化版 | `LLMWiki_simplified.md` | 快速概览、主题索引、日常参考 | 较小 |

- **新 Agent 启动时**：只加载 LLMWiki 简化版，快速了解历史上下文
- **需要深度查找时**：Agent 自行检索 raw_messages/ 下的 JSONL 文件
- **导入后**：新 Agent 调用 LLMWiki skill 从原始版自动生成简化版

### 为什么密钥单独一个层？

- 不是所有场景都需要导出密钥（纯备份 vs 真正迁移）
- 密钥有安全风险，需要用户显式确认
- 有些密钥存储在 Keychain 中，迁移平台后需要重新配置

### 云端部署方案

将 zip 包转为云端 Agent 可消费的格式：
1. 提取 README.md + 关键配置
2. 转为一段长文本 prompt
3. 在云端 Agent 对话框中发送
4. Agent 自己读取并配置

这是 Agent 迁移的终极形态：**一句话完成环境搭建**。

## 平台兼容性

| 平台 | Skills 支持 | MCP 支持 | Memory 支持 | 备注 |
|------|------------|----------|------------|------|
| WorkBuddy | ✅ 原生 | ✅ 原生 | ✅ 原生 | 来源平台 |
| Claude Code | ✅ CLAUDE.md | ❌ | ✅ 文件 | 需要转换格式 |
| OpenClaw | ✅ 原生 | ✅ 原生 | ✅ 文件 | 高度兼容 |
| Manus | ⚠️ 有限 | ❌ | ⚠️ 对话内 | 需要简化为 prompt |
| Codex CLI | ✅ AGENTS.md | ❌ | ✅ 文件 | 需要转换格式 |
| TRAE SOLO | ⚠️ 有限 | ❌ | ⚠️ 未知 | 待验证 |

## 迁移频率建议

- **轻量备份**：每周一次，不含密钥，不含 RAG
- **完整迁移**：换平台时，含密钥，含 RAG
- **云端部署**：考完试上云时，含密钥，不含 RAG（云端用远程 RAG）
