# 闲鱼智能运营 Skill

面向**已登录闲鱼网页版**的智能运营助手。通过浏览器自动化读取消息，AI 生成回复建议，人工确认后发送。

## 核心原则

1. **先读后操作**：先 snapshot 页面内容，再决定操作
2. **草稿优先**：默认生成回复草稿供用户确认，不直接发送
3. **价格谨慎**：涉及价格变动的操作必须人工确认
4. **身份校验**：每次回复前核对会话身份（卖家/买家）和商品信息
5. **人工兜底**：遇到纠纷、情绪激烈、大额交易等情况，建议人工接管

## 触发场景

当用户表达以下意图时触发：

- "帮我看看闲鱼有没有新消息"
- "这个买家问的怎么回"
- "帮我回复闲鱼买家"
- "帮我写个闲鱼商品描述"
- "帮我批量处理闲鱼消息"
- "这个闲鱼商品怎么定价"
- "帮我上架闲鱼"
- "闲鱼有人砍价怎么回"
- "有人下单了，帮我找便宜的"
- "同款比价"
- "帮我搜XX商品最低价"

## 工作流程

### 消息检查流程（每小时自动化）

```
1. 打开闲鱼网页版消息页 https://www.goofish.com/im
2. Snapshot 获取会话列表
3. 识别未读消息（有红点/新消息标记的会话）
4. 逐个进入未读会话，snapshot 读取最近消息
5. 根据意图分类生成回复草稿
6. 汇总所有待回复消息，附带 AI 建议回复
7. 用户确认/修改后，代为发送
```

### 消息回复流程（手动触发）

```
1. 用户指定要回复的会话或提供截图
2. 打开对应会话页面，snapshot 读取上下文
3. 校验：商品是否匹配、身份是否正确、消息上下文是否连贯
4. 根据 [reply-playbook.md] 分类规则生成回复草稿
5. 输出草稿 + 可选版本 + 说明
6. 用户确认 → 执行发送
7. 用户修改 → 使用修改后的内容发送
```

### 订单履约流程（买家下单后找更便宜的货源）

**⚠️ 绝对不自动下单、不自动付款、不自动购买任何商品。只做搜索和比价。**

```
1. 收到买家订单 → 提取商品关键信息（品牌/型号/关键词/价格）
2. 在闲鱼搜索同款商品：
   - URL: https://www.goofish.com/search?q=关键词
   - 逐个 snapshot 搜索结果
3. 筛选条件：
   - 价格低于买家支付价（留出利润空间）
   - 卖家信用极好（优先）/ 优秀
   - 有"XXX人想要"标记的优先（说明活跃可靠）
4. 生成比价表格，列出 Top 5 候选
5. 用户决定拍哪个 → 用户自己操作购买
```

### 比价输出格式

```
📦 买家需要：[商品关键词] | 买家支付价：¥XX

🔍 搜索结果（按价格升序，信用极好优先）：

| # | 标题 | 价格 | 信用 | 想要 | 利润(差价) |
|---|------|------|------|------|-----------|
| 1 | xxx | ¥XX | 极好 | 5人 | +¥XX |
| 2 | xxx | ¥XX | 优秀 | 2人 | +¥XX |

💡 推荐：第 X 个，信用极好 + 价格最低，利润 ¥XX

⚠️ 请选择要拍的候选，我帮你打开链接（支付和下单需要你自己操作）
```

```
1. 用户提供商品信息（图片、描述、价格意向）
2. 根据 [listing-playbook.md] 生成标题候选、正文、标签
3. 打开闲鱼发布页 https://www.goofish.com/publish
4. 逐步填写字段，每步截图确认
5. 最终预览截图给用户确认
6. 用户确认 → 点击发布
```

## 会话身份校验（必须执行）

在任何自动回复前，必须完成以下检查：

1. **核对商品**：当前会话关联的商品标题、价格、地区是否匹配
2. **核对身份**：确认自己是卖家还是买家
3. **核对上下文**：阅读最近 3-6 条消息，理解对话走向
4. **异常停止**：发现会话信息不一致时，不硬回，向用户确认

## 意图分类规则

参考 [references/reply-playbook.md] 中的详细规则：

| 分类 | 关键词/场景 | 回复策略 |
|------|------------|---------|
| **default** | 一般咨询、商品详情 | 快速、礼貌、降低决策成本 |
| **price** | 砍价、议价 | 先稳价 → 小幅让步 → 阶梯谈判 |
| **tech** | 成色、技术细节、规格 | 真实具体，不夸张 |
| **delivery** | 发货、自提、交易方式 | 明确时间地点方式 |
| **after-sales** | 退换、售后、纠纷 | 保守表达，以平台规则为准 |

## 输出格式

```

✅ 建议回复：
[AI 生成的回复]

[备选回复]

⚠️ 说明：
[为什么这样回复，如有需要特别注意的点]
```

```
2. [标题2]
3. [标题3]

📝 正文文案：
[商品描述正文]

🔖 标签关键词：
[标签1] [标签2] [标签3] ...

Q: [问题1]
A: [回答1]

A: [回答2]
```

## 人工接管触发条件

遇到以下情况，停止自动化，建议人工处理：

- 买家情绪激烈（辱骂、威胁、极度不满）
- 涉及大额砍价（超过原价 30%）
- 涉及真假、维修史、事故车等敏感问题
- 买家诱导脱离平台交易（加微信、线下转账等）
- 用户明确要求改用自己的语气

## 注意事项

- 闲鱼网页版 URL：`https://www.goofish.com`
- 消息页 URL：`https://www.goofish.com/im`
- 发布页 URL：`https://www.goofish.com/publish`
- 浏览器操作使用 `onezion-agent-browser-core` skill
- 避免短时间内大量操作，防止触发风控
- 每次批量处理建议不超过 10 个会话
