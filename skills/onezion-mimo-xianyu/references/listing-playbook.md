# 闲鱼商品上新与文案规则

## 商品文案生成流程

收到商品信息（图片/描述/价格）后，按以下结构生成完整文案：

---

## 标题生成规则

### 公式
```
[品牌/型号] + [核心卖点] + [成色/状态] + [差异化标签]
```

### 要求
- 控制在 20-30 字
- 包含搜索高频词（品牌名、型号名必须出现）
- 不要用"转让""急售"等降低价值感的词
- 可用：「自用」「9成新」「正品」「带票」等增加信任的词

### 示例

| 商品 | 差标题 | 好标题 |
|------|--------|--------|
| iPhone 15 Pro | 转让 iPhone 15 | iPhone 15 Pro 256G 国行 95新 自用 原装配件齐全 |
| MacBook Air | 急售笔记本电脑 | MacBook Air M3 16+512 深空灰 9成新 轻度使用半年 |
| 机械键盘 | Cherry键盘便宜卖 | Cherry MX3.0S 红轴 机械键盘 自用 成色完美 送键帽 |

---

## 正文文案结构

```
【商品】[品牌+型号+规格]

【成色】[外观+功能整体描述]

【配置/参数】
· [参数1]
· [参数2]
· [参数3]

【亮点】
· [卖点1]
· [卖点2]

【瑕疵】[如实说明小瑕疵，没有就说"基本无瑕疵"]

【配件】[包含的配件清单]

【交易】支持平台交易，可自提，可走快递
```

### 示例

```
【商品】AirPods Pro 2代 USB-C版 国行

【成色】95新，日常带壳使用，外观几乎无磨损

【配置】
· 主动降噪 + 通透模式
· USB-C 充电盒
· 国行正品，支持官网验证

【亮点】
· 降噪效果非常好，通勤神器
· 电池健康，续航无衰减

【瑕疵】充电盒底部有极轻微使用痕迹，不仔细看不到

【配件】原装充电盒 + 耳塞套装 + 原装数据线（无包装盒）

【交易】走平台交易，支持自提（天河区），也发快递顺丰到付/运费自理
```

## 标签生成

### 原则
- 品牌标签（必加）
- 型号标签
- 品类标签
- 使用场景标签
- 人群标签

### 示例
```
#AirPods #苹果耳机 #降噪耳机 #通勤好物 #二手耳机 #苹果
```

---

## 定价策略建议

### 定价参考
- **95新以上**：官方价 × 0.7-0.8
- **9成新**：官方价 × 0.55-0.65
- **8成新（有瑕疵）**：官方价 × 0.4-0.5
- **热门稀缺品**：可适当上调 5-10%

### 让步空间
- 标价时预留 5-10% 议价空间
- 在正文中暗示底线："价格已经很低了，不刀/小刀可商量"
