Create a simple, personal web game called "Kitty and Sheep" — a friendship game between a cat (Kimmie) and a sheep (Harry).

## Output
Create files in `/tmp/onezion-skills/games/claude-code/`:
- `index.html` — landing page with 3 buttons: "Play with Kitty and Sheep" (main, prominent), "Kitty Only", "Sheep Only"
- `kitty-and-sheep.html` — the main game page where both characters are together
- `cat.html` — solo Kitty page
- `sheep.html` — solo Sheep page

## Design Requirements
- **Simple, clean design** — white/pink/soft colors, NO meadow scenes, NO sky/clouds/grass decorations
- **Hug is the main/favorite interaction** — make it the biggest, most prominent button with a pink gradient
- The game should feel warm and personal, like a little gift between two people
- Mobile-friendly, single HTML files with inline CSS/JS
- ASCII art characters (cat and sheep) are fine, keep them simple
- Back links between pages

## Interaction Ideas
- **Hug** (primary) — triggers heart particle animation, shows a hug-related quote, increments hug counter
- **Chat** — shows a random quote from the real chat records
- **Play** — fun little animation with both characters
- Hug counter that persists during the session
- Quote bubble that shows the real messages

## Characters
- Kitty (🐱) — Kimmie's character, a cat. Can be moody, protective, sometimes stubborn
- Sheep (🐑) — Harry's character, a sheep. Can be sad, tired, but also happy and bouncy

## Vibe
The game should feel like reading a love letter disguised as a game. Not flashy, not over-engineered. Just warm. Like two people who care about each other, even when one is being a moody cat.
